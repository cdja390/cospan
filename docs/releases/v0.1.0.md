## Highlights

`cospan` **0.1.0** is the initial public release of Cospan—a pure-ESM, zero-runtime-dependency async delegation adapter connecting **Antigravity (`agy`)**, **OpenAI Codex (`codex`)**, **Claude Code (`claude`)**, and **DeepSeek Harness (`dsh`)**.

### 1. Unified 4-harness async protocol (`src/cli.mjs`, `src/job-worker.mjs`, `src/drivers/`)

- **Point-to-point background lifecycle**: `send` (detached worker), `wait` (exit codes `0/2/3/4/5`), `observe` (bounded `<= 8 KiB` JSON snapshot), `result`, `continue` (native session resume), `restart`, `cancel`, `status`, and foreground `ask`.
- **Workspace hygiene**: Out-of-tree job logs, specs, and diffs under `~/.cospan/trajectories/`; pre-run dirty path tracking and post-run workspace delta reporting on writable runs, plus `--readonly` guard warnings.
- **Process-tree cleanup & locking**: Descendant PID group termination on cancel/timeout and atomic state locking across concurrent jobs.

### 2. Verbatim `Model × Effort` & 3-layer sparse config (`src/config.mjs`)

- **No host-side model guessing**: Model shortcuts (`flash`/`carbon`/`argon`/`hydrogen`/`opus`/`sonnet` for `agy`, `sol`/`terra`/`astra`/`luna` for `codex`, `sonnet`/`opus`/`haiku`/`fable` for `claude`, `v4.1-flash`/`v4-pro` for `dsh`) and `--effort` tiers pass verbatim to Cospan and resolve deterministically at runtime.
- **Sparse layered config**: Built-ins → global (`~/.cospan/config.json`) → trajectory → workspace (`.cospan/config.json`), with override provenance in `cospan config --json` and sparse `{}` initialization.

### 3. Unified live sidebar & worktree family aggregation (`src/ui/`, `src/sidecar/`, `dsh/`)

- **Shared board across `agy` and `dsh`**: Sidecar HTTP server (`cospan_board` in Antigravity) and Cordis web bundle (`dsh/client.js` in DeepSeek Harness) display live background jobs, Q&A outputs, and cancel actions across all four targets.
- **Git worktree aggregation (`wt:*`)**: Automatically groups sibling worktree trajectories under the same repository family (`src/repo-family.mjs`).

### 4. Bundled MCP, host installers, zero-drift contracts & update hygiene (`src/mcp/`, `src/installer.mjs`, `src/update-check.mjs`)

- **Stdio MCP & native DSH tools**: Exposes `cospan_send`, `cospan_wait`, `cospan_observe`, `cospan_continue`, `cospan_result`, `cospan_cancel`, `cospan_status`, and `cospan_ask` outside host command sandboxes.
- **Zero-token contract verification & update check**: `cospan doctor --check` verifies installed binary `--help` flags against driver expectations; non-blocking 24h TTL update check and legacy config override warnings surface new releases and stale model pins cleanly.
